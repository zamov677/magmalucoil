# Telegram Mini App - Магма Лукойл Махачкала

Этот проект представляет собой премиальный Telegram Mini App для экспресс-пункта замены масла **«Магма Лукойл»** в Махачкале.

## Структура проекта
- `index.html` — Главный HTML-шаблон, реализующий SPA-интерфейс (Главная, Каталог, Запись, Кабинет).
- `styles.css` — Стилизация в премиальном темном оформлении с поддержкой переменных Telegram.
- `app.js` — Логика переключения вкладок, интерактивной карты Leaflet, мастера записи (4 шага) и корзины товаров.
- `assets/` — Графические ассеты (логотип и промо-баннер).

## Локальный запуск
Для работы интерактивной карты и загрузки скрипта Telegram WebApp, запустите локальный HTTP-сервер.

1. Установите простой локальный веб-сервер, если у вас его нет. Например, используя Node.js:
   ```bash
   npm install -g http-server
   ```
   Или запустите с помощью встроенного модуля Python:
   ```bash
   python -m http-server 8000
   ```
2. Перейдите в эту папку и запустите сервер:
   ```bash
   http-server -p 8000
   ```
3. Откройте `http://localhost:8000` в браузере для просмотра и отладки.

## Подключение к Telegram Bot
1. Откройте Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Создайте нового бота с помощью команды `/newbot`.
3. Создайте новое веб-приложение командой `/newapp`.
4. Выберите созданного бота, введите название приложения и описание.
5. Загрузите квадратную картинку (можно использовать `assets/magma_logo.png`).
6. В качестве **Web App URL** укажите адрес вашего развернутого приложения (для тестирования на телефоне можно использовать туннелирование, например [ngrok](https://ngrok.com/)):
   ```bash
   ngrok http 8000
   ```
   И скопируйте предоставленный HTTPS URL (например, `https://random-id.ngrok-free.app`) в BotFather.
7. После создания вы получите ссылку вида `t.me/your_bot/app_name`. Откройте её в Telegram на телефоне или ПК!
